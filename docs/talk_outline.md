## 削り順

持ち時間が足りないときは上から順に落とす。落としても話の筋が通るように
並べてある。

1. **#32 角運動量はどこへ行ったか** — #31 の一言 (「軌道の角運動量をもらって
   回り始めた」) で足りる。表は Appendix 送り
2. **#37 再開した計算だけ 3 倍遅い** — 計算機寄りの話。物理の聴衆には #36 の
   ほうが伝わりやすい
3. **#38 今回の構成の利点と弱点** — 安さは #26 が言う。代償 (いつ終わるか
   読めない) は #39 の冒頭に一言で足りる
4. **#23 書きかけから再開しないために** — #22 の図だけで「外に置く」は伝わる
5. **#18 格子とスケール感** — 8.62 ms と 222 m は #26 と #15 に一言ずつ移す
6. **#17 星の中身と、星の外** — 人工の大気は #30 (星の 94%) の注記と
   Appendix C で言える。ポリトロープは #16 に「中身は単純なモデル」と一言
7. **#7 前回と今回** — 解像度と計算機は #4 (前回やり残したこと) が、物質は
   #16 が言う。表で一覧したいかどうかで決める
8. **#13 なぜ軽い BH だと壊れるのか** — #11 の図と「BH を 2.8 倍重くしても、
   壊れる距離は 1.4 倍」の一言で代用できる。#12 (ISCO) は残す
9. **#29 動画** — 会場で動画が再生できないなら落とす (#28 の 3 コマで代用)
10. **#20 自宅 PC で解像度を落として試走** — #21 の冒頭に「自宅 PC には載らないので」と
   一言入れて統合。#4 の「再現できないと思っていた」も一緒に落とす

残す優先度が高いのは #4 (前回やり残したこと)、#9 (質量ギャップ)、
#10 (過去の BH + 中性子星との違い)、#11 (2 つの結末)、#12 (ISCO)、#28 (密度の 3 コマ)、
#30・#31 (残った物質と BH)、#34 (公開データとの一致)、#25・#26 (リレーと数字)、
#39 (応用性)。
#10 は質量ギャップと円盤をつなぐ役なので、#9 と #11 を残すなら一緒に残す。
