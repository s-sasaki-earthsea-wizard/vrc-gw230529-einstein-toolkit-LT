## 削り順

持ち時間が足りないときは上から順に落とす。落としても話の筋が通るように
並べてある。

1. **#30 角運動量はどこへ行ったか** — #29 の一言 (「軌道の角運動量をもらって
   回り始めた」) で足りる。表は Appendix 送り
2. **#35 再開した計算だけ 3 倍遅い** — 計算機寄りの話。物理の聴衆には #34 の
   ほうが伝わりやすい
3. **#21 書きかけから再開しないために** — #20 の図だけで「外に置く」は伝わる
4. **#16 格子とスケール感** — 8.62 ms と 222 m は #24 と #14 に一言ずつ移す
5. **#7 前回と今回** — 解像度と計算機は #4 (前回やり残したこと) が、物質は
   #15 が言う。表で一覧したいかどうかで決める
6. **#12 なぜ軽い BH だと壊れるのか** — #11 の図で定性的には伝わる。式を見せたい
   聴衆かどうかで決める
7. **#27 動画** — 会場で動画が再生できないなら落とす (#26 の 3 コマで代用)
8. **#18 自宅 PC には載らなかった** — #19 の冒頭に「自宅 PC には載らないので」と
   一言入れて統合

残す優先度が高いのは #4 (前回やり残したこと)、#9 (質量ギャップ)、
#10 (過去の BH + 中性子星との違い)、#11 (2 つの結末)、#26 (密度の 3 コマ)、
#28・#29 (残った物質と BH)、#32 (公開データとの一致)、#23・#24 (リレーと数字)。
#10 は質量ギャップと円盤をつなぐ役なので、#9 と #11 を残すなら一緒に残す。
