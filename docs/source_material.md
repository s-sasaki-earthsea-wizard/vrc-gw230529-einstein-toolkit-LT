スライドに出す数字を、出どころごとに並べる。略号は次のとおり。

- **infra**: [gw230529-einstein-toolkit-aws-tf](https://github.com/s-sasaki-earthsea-wizard/gw230529-einstein-toolkit-aws-tf)

### 1.1 過去の BH + 中性子星 (スライド #10)

| スライドの記述 | 出典 |
| --- | --- |
| GW200105: 8.9 M☉ + 1.9 M☉ (中央値) | LVK 2021 の要旨 |
| GW200115: 5.7 M☉ + 1.5 M☉ (中央値) | LVK 2021 の要旨 |
| どちらも「丸呑み」 | LVK 2021 §5.1 (潮汐破壊は起きない見積り。放出物質は 99% の確からしさで 10⁻⁶ M☉ 未満) |
| 光る BH + 中性子星合体は思ったより多いかも | LVK の要旨 (「電磁波を伴う合体の期待頻度が上がる」) |

- 「1 割の確率で破壊」は GW230529 で**潮汐破壊が起きたという意味ではない**。
  LVK は同じ節で、BH の外に残る物質の上限を 0.052 M☉ (99%) としている。
  電磁波は検出器 1 台で到来方向が絞れず、見つかっていない
- **質問への備え**: 「LVK の見積りは 1 割なのに、計算では壊れたのはなぜ？」
  LVK の確率は、質量・自転・状態方程式の幅で平均したもの。計算は中央値の質量、
  自転なし、Γ = 2 の星という 1 点で、この星の半径は約 14 km (§6 の図と同じ値)。
  GW170817 から見積もられた半径 (約 12 km、LVK, PRL 121, 161101 (2018)) より
  大きく、大きい星ほど壊れやすい。論文も「質量比が小さいことが主な理由」と
  書いている (論文 §3)

### 2.0 計算の設定の説明 (スライド #15〜#17)

| スライドの記述 | 根拠 |
| --- | --- |
| 論文の計算は英国のスーパーコンピュータで 2 ノード・256 コア・メモリ 140 GB | 論文 §2 (DiRAC/COSMA8、約 30 時間、約 7,680 CPU 時間)。**論文の記述として引用している** |
| BH は質量と自転だけで決まる | 無毛定理。電荷も持てるが天体ではほぼゼロ (質問されたら補足) |
| 本物の星では流体と電磁気力の両方が効く (磁気流体) | 論文 §1 (磁場と弱い相互作用は IllinoisGRMHD で扱えると書いている) |
| 今回の計算は電磁場なしで流体力だけ | 論文 §1 (磁場・弱い相互作用・有限温度の状態方程式は今後の拡張として挙げている)、sim README (general relativistic hydrodynamics) |
| 圧力は密度の 2 乗に比例 (ポリトロープ) | Γ = 2 ($P = K\rho^2$)。論文 §2 |
| 本物の中性子星の中身はまだよく分かっていない | 状態方程式の不定性。例えば GW170817 からの半径の制約 (LVK, PRL 121, 161101 (2018)) |
| 流体の計算は真空を扱えないので人工の大気で埋める | §5.3 と同じ (Appendix C) |
| 大気は星の中心より 7 桁薄い | 中心密度 1.26×10⁻³ (data の `rho_max.tsv`、t = 0) ÷ 大気 10⁻¹⁰ = 1.3×10⁷ |
| 大気を集めると 0.25 M☉ | §5.3 |

- 公開データのログ (`bhns_gw230529.out`) では 480 rank (12 ノード × 40 コア)・
  メモリ 438.5 GB で、論文の記述と値が違う (infra CLAUDE.md「インスタンス選定の
  再評価」)。スライドでは論文の値を論文の値として出し、食い違いの理由は推測しない
- 「圧力は密度の 2 乗に比例」は初期の星 (冷たいポリトロープ) の話。計算中は Γ 則
  $P = (\Gamma - 1)\rho\epsilon$ で、衝撃波の加熱も圧力に入る。スライドでは省いている
- 「7 桁薄い」は相対的な話で、大気の密度を SI に直すと約 6×10¹⁰ kg/m³ になる。
  「ごく薄い」を絶対的な値として読まれないように、比で言う

スライドの派生値:

- **BH の地平面の半径 10.6 km**: $2GM/c^2$ = 2 × 3.6 × 1.4766 km。data の
  t = 0 の既約質量 3.599 M☉ から出した面積半径 (その 2 倍) とも一致する
- **中心密度 7.8×10¹⁷ kg/m³**: data の `rho_max.tsv` の t = 0 (1.26×10⁻³)。
  原子核の飽和密度 約 2.7×10¹⁷ kg/m³ の約 3 倍
- **ISCO 32 km → 89 km**: $6GM/c^2$ を 3.6 M☉ と 10 M☉ で計算
- **潮汐破壊半径は 1.4 倍**: $(10/3.6)^{1/3}$ = 1.41。係数は 1 のオーダーで
  モデルに依るので、比だけを述べている

### 2.1 ISCO と潮汐破壊の説明 (スライド #12、#13、Appendix D)

| スライドの記述 | 根拠 |
| --- | --- |
| 人工衛星は速さを合わせればどの高さでも回れる、ずれても楕円になるだけ | ニュートン力学の点質量。有効ポテンシャル $-GM/r + L^2/2r^2$ はどの $L$ でも極小を持つ |
| BH のそばでは重力が逆 2 乗より急に強まる | Schwarzschild 時空の有効ポテンシャルの第 3 項 $-GML^2/(c^2 r^3)$ の言い換え |
| ISCO より内側には安定な円軌道が無い、$r_{\mathrm{ISCO}} = 6GM/c^2$ | 一般相対論の教科書の標準的な結果 (例: Carroll, *Spacetime and Geometry* (2004) 5 章) |
| 潮汐力は距離の 3 乗で弱まる | 星の手前と奥の引力の差: $GM/(r-R)^2 - GM/(r+R)^2 \approx 4GMR/r^3$。中心からの差なら $2GMR/r^3$ |
| 潮汐破壊半径 $r_{\mathrm{tid}} \sim R_{\mathrm{NS}} (2 M_{\mathrm{BH}}/M_{\mathrm{NS}})^{1/3}$ | 星の表面で $2GM_{\mathrm{BH}}R/r^3 = GM_{\mathrm{NS}}/R^2$ と置いた素朴な見積り |

- 「重力が逆 2 乗より強まる」は、有効ポテンシャルの補正項をニュートン的な力として
  読んだ言い方で、座標に依らない量ではない。聴衆向けの直感として使っている。
  質問されたら Appendix D の有効ポテンシャルで答える
- 潮汐破壊半径の係数は、Appendix D の式では $2^{1/3} \approx 1.26$、#11 の図では
  流体のロッシュ限界の 2.44 (§6)。どちらも $M_{\mathrm{BH}}^{1/3}$ に比例するので、
  スライドで使う比 (1.4 倍) は変わらない
- 「人工衛星」の比較は、地表や大気を無視した点質量としての話

## 5. 物理の結果 (本番 run の出力から)

`scripts/extract_run_data.py` で抜き出した [data/](data/) の時系列から読んだ値。
時刻は幾何単位 (M☉) で保存してあり、図とスライドではミリ秒に直している。

### 5.1 残骸ブラックホール — `remnant_bh.tsv`

QuasiLocalMeasures が地平面の上で測った質量 $M$ と角運動量 $J$。

| 量 | t = 0 | 最後 (8.55 ms) | 論文 (合体後 約 10 ms) |
| --- | --- | --- | --- |
| 質量 $M$ | 3.60 M☉ | **4.72 M☉** | 4.73 M☉ |
| 角運動量 $J$ | 0.007 | **13.49 M☉²** | — |
| 無次元スピン $J/M^2$ | 0.0005 | **0.60** | 0.61 |
| 既約質量 | 3.60 M☉ | 4.48 M☉ | — |

- 本番 run は合体後 5.1 ms で止めたので、質量もスピンもまだわずかに増えている
  (6.88 ms で 4.710 / 0.597、8.55 ms で 4.725 / 0.604)。論文の値へ近づく途中
- 論文の値から既約質量を計算すると 4.73 × √((1 + √(1 − 0.61²)) / 2) = 4.48 M☉ で、
  地平面の面積から直接出した値と一致する

### 5.2 角運動量の内訳

### 5.3 残った物質 — `rest_mass.tsv`

**格子全体の静止質量には、真空を埋める人工の大気が含まれる。**

| 量 | 値 [M☉] |
| --- | --- |
| 格子全体の静止質量 (t = 0) | 1.7552 |
| 中性子星の静止質量 (星を追う球の中、t = 0) | 1.5060 |
| 差 = 人工の大気 | **0.2492** |
| 検算: 大気の密度 10⁻¹⁰ × 格子の体積 2.4277×10⁹ | 0.2428 |
| 格子全体の静止質量 (最後、8.59 ms) | 0.3386 |
| 大気を引いた残り | **0.0893 = 星の 5.9%** |

- 大気を引かずに割ると 0.3386 / 1.7552 = 19% になり、「星の 2 割が残った」と
  読めてしまう。実際は約 6%
- 大気の質量は一定とみなして引いている。t = 0 の差と「密度 × 体積」の検算が
  3% 以内で合うので、結論 (約 6%) は動かない
- 積分は格子全体なので、地平面の内側にまだ残っている物質があれば含まれる。
  **BH の外に残った量の上限**として読む
- 収支の確認: BH の質量の増加 (4.72 − 3.60 = 1.12 M☉) と、星の重力質量 1.4 M☉、
  重力波のエネルギー 0.035 M☉ (論文: 全質量の 0.70%) を並べると、外に残るのは
  0.1 M☉ の桁で、19% (0.29 M☉) ではなく 6% (0.09 M☉) のほうと整合する

`tidal_vs_plunge.svg` は模式図。1 km = 1.5 px の同じ縮尺で、地平面
(10.6 km / 29.5 km) と ISCO (32 km / 89 km) は計算値、潮汐破壊半径は
流体のロッシュ限界の係数 2.44 と星の半径 14 km で描いた目安 (47 km / 66 km)。
凡例の ISCO は英語の正式名 (Innermost Stable Circular Orbit、最内安定円軌道) だけを書き、意味はスライド本文で
「この内側では安定に回れず、落ちる一方」と説明している。「内側は回れない」とは
書かない。ISCO の内側にも不安定な円軌道はある (光子球 $3GM/c^2$ まで)。
