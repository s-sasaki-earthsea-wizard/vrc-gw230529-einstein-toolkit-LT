# スライドの数字の出典と導出

スライドに出す数字を、出どころごとに並べる。略号は次のとおり。

- **sim**: [gw230529-einstein-toolkit](https://github.com/s-sasaki-earthsea-wizard/gw230529-einstein-toolkit)
- **infra**: [gw230529-einstein-toolkit-aws-tf](https://github.com/s-sasaki-earthsea-wizard/gw230529-einstein-toolkit-aws-tf)
- **論文**: Matur et al., [arXiv:2603.07374v2](https://arxiv.org/abs/2603.07374)
- **LVK**: LIGO-Virgo-KAGRA, [Astrophys. J. Lett. 970, L34 (2024)](https://arxiv.org/abs/2404.04248)
- **data**: このリポジトリの [data/](data/) (本番 run の出力から抜き出した時系列)

単位の換算は IAU 2015 の $GM_\odot$ による:
1 M☉ = 1.4766 km = 4.9255 μs、密度は 1 M☉⁻² = 6.1758×10²⁰ kg/m³。

## 5. 物理の結果 (本番 run の出力から)

`scripts/extract_run_data.py` で抜き出した [data/](data/) の時系列から読んだ値。
時刻は幾何単位 (M☉) で保存してあり、図とスライドではミリ秒に直している。

### 5.1 残骸ブラックホール — `remnant_bh.tsv`

QuasiLocalMeasures が地平面の上で測った質量 $M$ と角運動量 $J$。

| 量 | t = 0 | 最後 (8.55 ms) | 論文 (合体後 約 10 ms) |
| --- | --- | --- | --- |
| 質量 $M$ | 3.60 M☉ | **4.72 M☉** | 4.73 M☉ |
| 角運動量 $J$ | 0.007 | **13.49 M☉²** | — |
| 無次元スピン $J/M^2$ | 0.0005 | **0.60** | 0.61 |
| 既約質量 | 3.60 M☉ | 4.48 M☉ | — |

- 本番 run は合体後 5.1 ms で止めたので、質量もスピンもまだわずかに増えている
  (6.88 ms で 4.710 / 0.597、8.55 ms で 4.725 / 0.604)。論文の値へ近づく途中
- 論文の値から既約質量を計算すると 4.73 × √((1 + √(1 − 0.61²)) / 2) = 4.48 M☉ で、
  地平面の面積から直接出した値と一致する

### 5.2 角運動量の内訳

| | 値 [M☉²] | 出典 |
| --- | --- | --- |
| はじめの連星 $J_0$ | 17.04 | 論文 §2 |
| 合体後の BH | 13.49 (79%) | data |
| 重力波 | 1.86 (10.91%) | 論文 表 1 (中解像度) |
| 残り | 約 1.7 (約 10%) | 引き算 |

「残り」は引き算で出した値で、BH の外に残る物質が持つ分と解釈している。
直接測った量ではないので、スライドでも「外の物質など」と書いている。
重力波の分は論文の値 (合体後 約 10 ms まで) を借りている。

### 5.3 残った物質 — `rest_mass.tsv`

**格子全体の静止質量には、真空を埋める人工の大気が含まれる。**

| 量 | 値 [M☉] |
| --- | --- |
| 格子全体の静止質量 (t = 0) | 1.7552 |
| 中性子星の静止質量 (星を追う球の中、t = 0) | 1.5060 |
| 差 = 人工の大気 | **0.2492** |
| 検算: 大気の密度 10⁻¹⁰ × 格子の体積 2.4277×10⁹ | 0.2428 |
| 格子全体の静止質量 (最後、8.59 ms) | 0.3386 |
| 大気を引いた残り | **0.0893 = 星の 5.9%** |

- 大気を引かずに割ると 0.3386 / 1.7552 = 19% になり、「星の 2 割が残った」と
  読めてしまう。実際は約 6%
- 大気の質量は一定とみなして引いている。t = 0 の差と「密度 × 体積」の検算が
  3% 以内で合うので、結論 (約 6%) は動かない
- 積分は格子全体なので、地平面の内側にまだ残っている物質があれば含まれる。
  **BH の外に残った量の上限**として読む
- 収支の確認: BH の質量の増加 (4.72 − 3.60 = 1.12 M☉) と、星の重力質量 1.4 M☉、
  重力波のエネルギー 0.035 M☉ (論文: 全質量の 0.70%) を並べると、外に残るのは
  0.1 M☉ の桁で、19% (0.29 M☉) ではなく 6% (0.09 M☉) のほうと整合する

### 5.4 最大密度 — `rho_max.tsv`

t = 0 で 7.8×10¹⁷ kg/m³、最後 (8.59 ms) で 4.4×10¹⁵ kg/m³。約 1/180。

### 5.5 重力波の波形

図は infra の `postprocessing/plot_psi4.py` の出力。Ψ4 の (l, m) = (2, 2) 成分を
中心から 500 M☉ = 738 km の球面で取り出したもの。

| スライドの記述 | 値 | 導出 |
| --- | --- | --- |
| 最初の 2.5 ms は波が届かない | 2.46 ms | 738 km ÷ 光速 |
| 振幅のピーク | 5.98 ms | 図の注記。合体 3.51 ms + 2.46 ms |
| 周波数 0.8 → 1.8 kHz | 4.1 ms で 790 Hz、ピークで 1,790 Hz | 複素 Ψ4 の位相の時間微分 ÷ 2π |
| 公開データとの差 | 最大 4.4×10⁻⁴ (ピーク振幅比) | infra README |
| 再開で段差なし | 差は最初の中断より前に 10⁻¹⁵ の床に達する | infra README |

- 2.5〜3 ms の小さな乱れは、初期データに含まれる余分な放射 (junk radiation) が
  球面に届いたもの。スライドでは触れていないが、質問されたら答える
- 周波数は Ψ4 の位相から出した。歪み $h$ への 2 回積分はしていない
- 比較したのは波形の主要な成分ひとつだけで、計算領域全体の検証ではない
